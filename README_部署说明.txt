========================================================================
                      英语汇学 (Smart English) 部署说明
========================================================================

一、环境要求：
1. Python 3.9 或更高版本
2. Node.js 16.0 或更高版本 (支持 npm)

二、快速一键运行（推荐）：
双击运行项目根目录下的 `启动项目.bat` 即可自动安装依赖并同时启动前后端服务。

三、手动部署与运行步骤：

【1. 后端服务启动】
1) 打开命令行终端，进入项目根目录：
2) 安装依赖：
   pip install -r backend/requirements.txt
3) 启动 FastAPI 服务：
   python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000

【2. 前端服务启动】
1) 打开新的命令行终端，进入项目根目录：
2) 安装前端依赖：
   npm install
3) 启动开发服务：
   npm run dev
4) 浏览器访问控制台输出的地址（默认 http://localhost:5173）即可体验项目。
